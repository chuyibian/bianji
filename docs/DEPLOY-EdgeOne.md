# 把「便记」装到自己的手机上（EdgeOne，无需域名）

> 适用场景：只给自己用、人在**中国大陆以外**（例如新加坡）、不买域名。
> 资料核对日期：2026-10-29。EdgeOne **Pages** 已更名为 EdgeOne **Makers**，旧的叫法和命令仍然有效。按钮文字以控制台实际显示为准。

---

## 三件事先知道

1. **加速区域选「全球（不含中国大陆）」。** 按官方文档，这个区域的默认域名在中国大陆以外**可以直接访问**，不需要自定义域名，也不需要备案。（另外两个区域即使在海外，默认域名也要用 3 小时后失效的预览链接。）
2. **安装时要用「项目域名」，不要用「部署域名」。** EdgeOne 给每个项目分配一个固定的项目域名，同时每次部署都会生成一个新的部署域名。PWA 的数据是按网址存的：如果你从部署域名安装，下次更新后网址就变了，之前的记录在新网址下看不到。
3. **数据只在手机里。** 建议每月在「数据 → 导出备份」导出一次。

---

## 第 1 步：注册

人在海外，建议用**国际站**：打开 **edgeone.ai** 注册登录（文档说明可以用 Gmail 注册），然后进入 Makers（Pages）控制台。

> 国内站 cloud.tencent.com 一般要求先完成实名认证，海外用户用国际站更省事。

## 第 2 步：上传

1. 控制台 → **创建项目** → **直接上传**
2. **项目名称**：小写字母、数字或连字符，5–50 个字符，例如 `bianji-app`
3. **加速区域**：**全球（不含中国大陆）**（创建后基本不能修改）
4. 把本项目的 **`public` 文件夹**整个拖进去（`index.html` 必须在最外层，`public/` 正好满足），点击 **开始部署**

如果拖文件夹不成功，就先打包成 ZIP 再上传：

```bash
cd /Users/chuyibian/Projects/poop/public && zip -r ../bianji.zip . -x '.*'
```

**或者用命令行**（适合以后频繁更新）：

```bash
npm install -g edgeone
```

```bash
edgeone login
```

（登录时选 **Global**）

```bash
edgeone makers deploy /Users/chuyibian/Projects/poop/public -n bianji-app
```

## 第 3 步：找到项目域名并验证

1. 打开项目的「项目概览」或「域名管理」，找到**项目域名**（固定不变的那个，形如 `bianji-app-xxxxxxxx.edgeone.xxx`）
2. 先在电脑浏览器里打开，能看到「记录」按钮就成功了

> **如果打开后显示 401：**说明这个默认域名仍然需要预览令牌。这一点官方文档写的是可以直接访问，但没有实际验证过。遇到这种情况，最省事的替代方案是 Cloudflare Pages：把 `public` 文件夹拖进去，就能得到一个永久免费的 `xxx.pages.dev` 地址，用法完全一样。

## 第 4 步：装到 iPhone

1. 用 **Safari** 打开项目域名（必须是 Safari）
2. 点底部的**分享**按钮 → **添加到主屏幕** → **添加**
3. 从主屏幕的「便记」图标打开：全屏运行，离线也能用

安卓：用 Chrome 打开 → 右上角菜单 → **安装应用**。

---

## 以后更新

1. 修改 `public/` 里的文件
2. 控制台 → 项目 → **构建部署** → **新建部署** → 拖入新的 `public` 文件夹（或者重新运行上面的 `edgeone makers deploy` 命令）
3. 手机上：打开 app 一次，它会在后台下载新版本，**第二次打开时生效**

项目域名不会变，所以数据不受影响。

## 免费额度

对这个项目完全够用：40 个项目、5GB 存储、免费 HTTPS、流量和请求都不限量。
